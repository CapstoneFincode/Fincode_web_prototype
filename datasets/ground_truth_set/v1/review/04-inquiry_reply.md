Visits는 화면 열기 횟수, Completed는 신청서 제출 완료 건수라서 서로 일치할 필요가 없다. 2027-04-01~2027-04-07 예시는 86회와 24건이며 작성 중인 5건은 완료 건수에서 제외한다. 내려받은 보고서는 자동 갱신되지 않아 기간 변경 후 다시 내려받아야 하며 현재 기능 수정은 필요 없다.

**필수 정보와 원문 근거**

1. Visits는 화면을 연 횟수를 집계한다.

> Visits는 화면을 연 횟수이므로

2. Completed는 제출을 마친 신청서 수이다.

> Completed는 제출을 끝낸 신청서 수이며

3. 예시 화면 열기는 86회이고 제출 완료는 24건이다.

> 화면 열기는 86회이고 제출 완료는 24건입니다.

4. 작성 중 5건은 완료 수에 포함하지 않는다.

> 작성 중인 신청서 5건은 완료 24건에 더하지 않습니다.

5. 기간을 변경하면 보고서를 다시 내려받아야 한다.

> 기간을 바꾼 뒤에도 기존 파일을 열면 예전 수치가 남으므로 새로 내려받아야 합니다.

6. 현재 집계 기능 수정은 필요 없다.

> 현재 집계 기능의 수정 작업은 필요하지 않습니다.
