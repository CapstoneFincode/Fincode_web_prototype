# 핀코드 · LLM Security Lab

한림대학교 캡스톤디자인 **LLM 프롬프트 인젝션 공격·방어 실험 플랫폼**의 첫 웹 UI 프로토타입입니다.

## 현재 동작하는 기능

- 대시보드, 이메일 요약기, 공격 실험, 데이터 관리, 실험 결과, 개발 현황 화면
- 합성 정상 이메일과 저장된 기준 요약 미리보기
- 정상 데이터·공격 시나리오 추가, 편집, 검색, 상세 확인
- 직접 등록한 정상 데이터의 검토 상태 관리
- 실험 모델·방어 후보·반복 횟수·시나리오 선택 및 미실행 계획 저장
- 브라우저 저장, JSON 백업·가져오기, 기존 실험 CSV 내보내기
- 기존 팀 실험 6건과 자동 판정/재검토 추정치 구분
- 첨부파일 선택, 확장자·크기·개수 확인 (내용 추출 없음)
- 의사결정 기록 추가

## 아직 연결하지 않은 기능

HAI-GPT 호출, 실제 모델 목록 조회, Python 백엔드, 팀 공용 DB, 문서 텍스트 추출, 이미지 OCR, 방어 실행, ASR/FPR 자동 평가, 토큰·응답시간 측정, promptfoo 결과 JSON 파싱은 구현 전입니다.

키를 입력하거나 저장하는 UI가 없습니다. API 키는 후속 서버의 환경변수에서만 관리할 계획입니다. 현재 입력 데이터는 서버로 전송되지 않습니다. 외부 Google Fonts 요청이 불가능하면 시스템 글꼴을 사용합니다.

## 데이터 해석

- `dist/data.js`의 기존 실험은 팀이 제공한 **2026-09-30 API TEST 발표자료**의 집계값입니다.
- 모델명은 그 자료에 기재된 문자열이며 현재 제공 모델 목록이나 정식 모델 식별자를 검증한 값이 아닙니다.
- 확장 DeepSeek 실험: 자동 ASR **30/49 = 61.22%**. 팀이 이견을 제시한 4건을 제외한 **26/49 = 53.06%**는 재검토 추정치이며 원본을 수정하지 않습니다.
- 5개의 정상 데이터와 7개의 공격 시나리오는 UI 검토용 합성 예시입니다. Ground Truth 완료 수에는 포함하지 않습니다.
- 정상 기준 DB는 원문과 기준 요약을 연결합니다. 직접 등록하고 검토 완료로 표시한 정상 데이터만 목표 100건의 진행 수에 포함합니다.
- 로컬 편집 데이터를 가져올 때는 구조만 검증합니다. 내용의 진실성이나 사람 검토의 실제 수행을 자동으로 보증하지 않습니다.
- 실험 계획에는 저장 당시 공격 시나리오의 사본이 포함됩니다. 이후 시나리오를 수정·삭제해도 과거 계획은 바뀌지 않습니다.

## 실행

외부 패키지 설치나 빌드 단계가 없는 HTML/CSS/ES module 프로젝트입니다.

```bash
python3 -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 엽니다. ES module을 사용하므로 파일을 직접 더블클릭하지 말고 HTTP로 제공해야 합니다.

### Docker

```bash
docker build -t fincode-lab .
docker run --rm -p 8080:80 fincode-lab
```

`http://localhost:8080`에서 사용합니다. 이 실행 설정은 프론트엔드 프로토타입만 제공합니다. 백엔드와 DB의 Docker 구성은 후속 단계에서 추가합니다. 이번 작업 환경에서는 Docker 엔진 실행 검증을 수행하지 않았습니다.

### 검사

```bash
npm run check
node --test tests/prototype.test.mjs
```

자동 검사는 데이터 검증, 집계 정확성, 저장 데이터 복원, HTML 이스케이프 및 각 화면 렌더링을 확인합니다. 브라우저 레이아웃·클릭 검사를 대체하지 않습니다. 이번 환경에서는 지원되는 브라우저 QA 도구가 없어 브라우저 시각 검사를 수행하지 않았습니다.

## 저장 및 배포

개인 데이터는 `localStorage`의 `fincode-lab-v1`에 저장됩니다. 서버 DB나 사용자 계정 간 동기화가 아니므로 필요한 데이터는 JSON으로 내보내세요. 브라우저 데이터 삭제 시 로컬 기록도 삭제됩니다. 가져오기는 현재 로컬 데이터를 교체하기 전에 확인을 받습니다.

이 저장소는 CapstoneFincode 팀이 검토하고 이어서 개발할 웹 프로토타입 소스입니다. 저장소 이름은 `CapstoneFincode/Fincode_web_prototype`입니다. 첫 프로토타입 전체 소스를 포함합니다.

UI 검토용 사이트: https://fincode-security-lab.tinyhawk128.chatgpt.site (기본 비공개이므로 팀원에게 접근 권한이 자동으로 주어지지는 않습니다).

이 커밋은 GitHub 호스팅을 설정하지 않습니다. 정적 사이트 호스팅에서는 `dist/`를 제공하면 됩니다. 팀 공용 클라우드 배포와 Python 백엔드는 후속 작업입니다. 별도 미리보기 서비스의 내부 호스팅 식별자는 이 저장소에 포함하지 않습니다.

## 파일 구성

- `dist/index.html`: 진입점
- `dist/style.css`: 데스크톱·태블릿·모바일 UI
- `dist/app.js`: 화면 이동, 입력, 데이터 관리, 실험 계획
- `dist/data.js`: 출처가 구분된 기존 실험과 합성 예시
- `docs/decisions.md`: 구현 결정 및 다음 단계
- `tests/prototype.test.mjs`: 프로토타입 데이터·렌더링 검사
