# 개발 의사결정

## 2026-10-14 — 실제 본문 요약과 측정 경로 연결

**배경:** 17시 지도교수 미팅에서 입력 → 실제 모델 응답 → 토큰·응답시간 확인 흐름을 시연하는 것이 UI 확장보다 우선이다.

**결정:** BAZE의 OpenAI 호환 `GET /models/?type=llm` 및 `POST /chat/completions/`를 사용한다. 과거 발표자료 모델명은 결과 기록에만 유지하고 실행 모델은 현재 API 목록에서 선택한다. Codex 계열은 Chat Completions 미지원 안내에 따라 목록에서 제외한다.

**실행 환경:** Python FastAPI 서버를 팀의 Docker 재현 경로로 추가한다. 기존 비공개 웹 호스팅은 JavaScript Worker 환경이므로 동일 API 계약의 서버 어댑터를 배포한다. 두 경로는 `config/email-baseline.json`의 시스템 프롬프트·버전·출력 제한·타임아웃을 공유한다. 기존 UI를 `public/`로 옮기고 호스팅에 필요한 Vinext 빌드 구성을 추가했다. 공용 DB는 이번 범위에 포함하지 않는다.

**실험 기준:** 방어 미적용 베이스라인만 실제 실행한다. 모델 제공자의 자체 안전 정책은 그대로 적용되며 공격 성공을 보장하지 않는다. 첨부파일과 미구현 방어 설정은 요청 단계에서 명시적으로 거절한다. 공격 입력을 탐지·차단하는 별도 방어를 이번에 몰래 추가하지 않는다.

**측정 정의:** `usage`가 제공하는 입력·출력·전체·추론 토큰을 그대로 매핑한다. 누락값은 `null`이며 화면에서는 `—`로 표시한다. 응답시간은 서버에서 게이트웨이 요청 시작부터 전체 JSON 응답을 읽은 시점까지다. 브라우저 왕복시간·TTFT·모델 내부 연산시간과 다르다. 빈 응답에도 사용량이 있으면 표시한다. 실제 응답을 기준 요약으로 대체하지 않으며 자동 재시도로 중복 호출하지 않는다.

**인증:** `BAZE_API_KEY`는 서버 환경변수로만 읽는다. 고정 게이트웨이 주소로만 전송하며 클라이언트에 키를 반환하지 않는다. 현재 코딩 에이전트 자체의 실행 모델이나 전역 설정은 변경하지 않는다. 전달받은 문서의 코딩 도구 설정과 이메일 앱 통합을 구분한다.

**제약:** 키가 등록되기 전에는 실모델 성공 검증을 완료했다고 표현하지 않는다. 3개 팀원 키의 할당·쿼터·사용자별 선택은 후속 작업이다. 현재 비공개 웹은 기존 소유자 접근 범위를 유지한다. Docker의 기본 포트는 localhost에만 노출하며 외부 공개 전에 인증·사용량 제한을 설계해야 한다.

**실패와 수정:** 첫 호스팅 모델 목록 요청은 즉시 502로 실패했지만 게이트웨이 직접 조회는 성공했다. 설치된 고정 버전 workerd에서 `redirect: 'error'`가 지원되지 않아 네트워크 호출 전에 예외가 발생함을 오프라인으로 재현했다. Node의 모의 fetch 테스트는 이 런타임 차이를 발견하지 못했다. `redirect: 'manual'`로 바꾸고 3xx를 오류로 처리해 다른 주소로 자격증명이 전달되지 않게 했다. 실제 workerd의 기본 fetch를 사용하는 회귀 테스트로 모델 목록·요약 성공과 리디렉션 미추적을 확인했다. 이 테스트는 외부 호출이나 실제 키를 사용하지 않는다.

**확인 결과:** 서버 비밀 환경변수 등록 후 2026-10-14 13:53 KST에 비공개 호스팅 API의 health·모델 목록 조회와 `gemini-3.5-flash-lite`의 합성 정상 이메일 `GT-S01` 요약 1회가 성공했다. 목록은 60개였으며 모두 호출해 검증한 것은 아니다. 입력 153·출력 114·전체 267토큰, 응답시간 2,144ms, 추론 토큰 미제공, 필수 정보 4개 포함을 [검증 기록](verification/2026-10-14-baze-live.json)에 남겼다. 단일 연결 확인이며 성능 벤치마크로 해석하지 않는다. 오프라인 45개 검사와 호스팅 빌드가 통과했고 브라우저 클릭·Docker 실행·Python 실모델 호출은 검증하지 않았다.

**공식 자료:** [에이전트 설정](https://docs.mindlogic.ai/agent-setup/prompt.md), [OpenAPI](https://docs.mindlogic.ai/openapi.json), [Chat Completions](https://docs.mindlogic.ai/docs/general/api-gateway/reference/chat-completions.md). 2026-10-14 확인. 일부 추론 모델은 출력 예산에 추론 토큰을 포함하므로 문서 권장 최소값 16,384를 설정했다. 이 값은 실제 사용량이 아니라 최대 한도다.

## 2026-10-12 — UI를 먼저 만드는 첫 버전

**배경:** 10월 29일 중간보고에서 실험 결과와 플랫폼 사용 흐름을 함께 보여주고, 이메일 요약기부터 연결한다.

**결정:** 설치·빌드 없이 실행 가능한 정적 프론트엔드를 먼저 구현한다. 사용자 데이터 저장은 브라우저에서 처리하며 JSON 백업을 제공한다. 최종 프론트엔드 프레임워크, 백엔드 API 및 DB는 확정하지 않는다.

**대안과 이유:** 처음부터 인증·공용 DB·LLM 호출을 함께 구현하면 아직 제공되지 않은 HAI-GPT API 규격과 키, 미확정 평가 기준을 추정해야 한다. 이번 단계는 UI와 데이터 입력 계약을 검토할 수 있도록 범위를 정했다.

**출처 구분:** 최신 10월 발표자료를 플랫폼 방향으로 사용하고, 9월 API TEST 결과는 과거 기록으로 표시한다. 합성 예시와 실측값은 섞지 않는다. 방어 효과와 정상 데이터 100건은 달성했다고 표시하지 않는다.

**후속 리스크:** 실제 모델 목록, 문서/OCR 처리 규격, 결과 판정 스키마에 따라 필드가 바뀔 수 있다. 로컬 저장은 팀 공용 DB를 대체하지 않는다. 실제 이메일을 데이터셋으로 옮길 때 필요한 개인정보 제거 범위를 팀이 확인해야 한다.

**배포 범위:** 이번 사이트는 UI 검토용 비공개 호스팅이다. Dockerfile은 정적 프론트엔드 재현용이며 최종 Python 백엔드 배포는 포함하지 않는다. 학교 GitHub 협업/기여 증빙 요구는 팀 저장소에서 별도로 충족해야 한다.
