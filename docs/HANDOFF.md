## 기존 실험의 해석

모델명과 수치는 제공한 9월 30일 발표자료 기준이며, 현재 웹에서 재실행한 값이 아니다.

| 모델 표기 | 공격 유형 | 시도 수 | 성공 수 | 자동 ASR |
|---|---:|---:|---:|---:|
| gemini-3.5-flash-lite | 3종 | 27 | 17 | 62.96% |
| gemini-3.1-flash-lite | 3종 | 29 | 17 | 58.62% |
| deepseek-flash | 3종 | 29 | 16 | 55.17% |
| deepseek-v4-flash | 3종 | 29 | 16 | 55.17% |
| gemini-3.5-flash-lite | 5종 | 49 | 31 | 63.27% |
| deepseek-flash | 5종 | 49 | 30 | 61.22% |

- 공격 표식을 인용하거나 거부 설명에 포함한 것과 실제 목표 행동을 수행한 것을 구분하도록 판정 기준을 설계해야 한다.

3. 사용자가 실제 연동을 요청하면 HAI-GPT API 문서, 엔드포인트, 허용 모델 목록을 확인한 뒤 서버 호출 구조를 구체화한다. 비밀 API 키를 채팅이나 GitHub에 노출하지 않는다.

5. 정상·공격 데이터를 소량으로 먼저 검증하고 DB, 첨부 처리, 방어·평가 기능을 단계적으로 확장한다.
