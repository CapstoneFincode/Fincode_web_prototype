## 검증과 해석 한계

자동 테스트 41개 통과. 기존 36개에 고정 데이터 회귀, 성공 표식을 바꾼 일반 지시, 정상 업무 문구, 태그 페이로드/이모지 구분, 허용 원문 보존 검사를 추가했다. 추가 문구는 단위 테스트용이며 실험 데이터나 Ground Truth에 추가하지 않았다. 네 설정×169건×3회 Mock 통합 확인도 수행했다. 실제 LLM 호출과 원본 DB 조회는 이번 보강에서 수행하지 않았다.

**69건을 직접 분석해 고친 규칙이므로 100%는 보정에 사용한 기존 집합의 탐지율이다. 미지 공격 일반화·실제 ASR 감소·모든 정상 메일의 무오탐을 입증하지 않는다.** 단순 반복 테스트를 독립 검증으로 보지 않는다. 정상 100건의 관측 차단율 0%와 모델 거부까지 포함한 최종 FPR도 구분해야 한다.

요약 금지 문구나 인젝션 사례를 인용한 보안 교육 메일은 정상이어도 규칙에 걸릴 수 있다. 이번 데이터에 없는 그 경계는 미해결이다. 무조건 예외 처리하면 공격이 교육·인용으로 위장해 우회할 수 있어 예외를 추가하지 않았다. 독립적인 새 정상/공격 검증 집합에서 오탐·누락을 확인한 후 정책을 결정해야 한다. 현재 실험용 규칙이며 메인 적용 판단은 보류다.
